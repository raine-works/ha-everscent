# Installation

EverScent is a custom integration. It needs Home Assistant 2024.12.0 or newer.

## Home Assistant Marketplace (recommended)

[![Open your Home Assistant instance and open this repository in the Home Assistant Marketplace.](https://my.home-assistant.io/badges/marketplace_repository.svg)](https://my.home-assistant.io/redirect/marketplace_repository/?owner=raine-works&repository=ha-everscent&category=integration)

1. Click the button above, or open the Marketplace in Settings → Marketplace.
2. If EverScent is not listed, add `https://github.com/raine-works/ha-everscent` as a custom repository of type Integration.
3. Download **EverScent**.
4. Restart Home Assistant.
5. Continue with [setup](setup.md).

## Manual

1. Copy the `custom_components/everscent` folder from the repository into your Home Assistant `config/custom_components/` folder.
2. Restart Home Assistant.
3. Continue with [setup](setup.md).
